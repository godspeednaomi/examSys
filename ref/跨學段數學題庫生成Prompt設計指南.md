## 1. 文件目的與適用範圍

本文件提供一套可供 Perplexity 產生數學試題、詳解、配分規準與題庫標籤的 Prompt 設計規格。產出目標不是直接形成 PDF、Word 或試卷排版，而是建立可由後續程式讀取、驗證、組卷與轉換格式的結構化資料。

本規格適用於：

- 國小、國中與高中數學。
- 一般複習卷、單元卷、診斷卷、資優加深卷與綜合評量。
- 題目卷、答案卷、逐步詳解卷與教師評分規準。
- 以 JSON 為核心資料交換格式的自動化題庫或文件產生系統。

原始參考試卷採四大題、19 題、100 分與 60 分鐘的設計，題型包含計算與推理填空、選擇題、應用推理題與資優挑戰題；詳解則強調策略辨識、逐步推理、驗算與常見錯誤診斷。此設計可作為預設範本，但不限制其他年級或主題使用不同題型配置。

## 2. 設計原則

### 2.1 分離四種資訊

題庫資料至少要清楚區分下列四類資訊，避免將不同層次混為一談。

| 資訊層次 | 說明 | 範例：三角函數 |
|---|---|---|
| 課程領域 | 數學的大分類 | `trigonometry` |
| 主題與子主題 | 實際要考的知識內容 | 三角函數、和差角公式 |
| 能力與任務 | 學生需要完成的數學活動 | 化簡、求精確值、判讀圖形、證明 |
| 解題策略 | 可採用的思考或運算方法 | 單位圓、公式代換、圖形判讀、反代驗算 |

例如，「間隔法」不是數學課程主題，而是處理植樹、鋸木頭、排隊、分段等題目的策略；「倒推法」也不是國小限定的主題，而可用於運算流程、方程式或反函數觀點。

### 2.2 結構化優先

輸出資料要優先支援程式處理，而非人類閱讀的排版美觀。因此每題應有固定欄位、明確資料型別、唯一題號、可驗證答案，以及可加總的配分規準。

### 2.3 可追溯與可診斷

每題應記錄考察概念、解題策略、常見錯誤、驗算方式與部分給分規準。這可支援後續：

- 依主題、難度或策略自動組卷。
- 避免同一張試卷重複考查相同結構。
- 從學生錯題回推需補強的觀念。
- 自動產生學生版、答案版、詳解版與教師版。
- 依標籤建立題庫搜尋、推薦與學習診斷。

### 2.4 依學段調整

同一個主題在不同學段可有不同深度與表徵。例如「函數」在國小可以是表格與對應關係，在國中可以是一次函數與二次函數，在高中則可擴展到指數、對數、三角、微積分與函數分析。

## 3. 跨學段數學知識架構

以下為建議的 `curriculum_domain` 標準代碼與適用範圍。系統可將這些代碼作為最上層分類，再往下加入 `topic`、`subtopic`、`concepts` 與 `skills`。

| 領域代碼 | 數學領域 | 國小常見內容 | 國中常見內容 | 高中常見內容 |
|---|---|---|---|---|
| `number` | 數與運算 | 整數、四則運算、分數、小數、倍數因數 | 有理數、平方根、指數律、科學記號 | 實數、複數、絕對值、不等式、指數與對數 |
| `algebra` | 代數與式 | 簡易數量關係、未知量、規律 | 一元一次方程式、聯立方程式、多項式、因式分解 | 多項式、方程式、不等式、指數對數、複數、矩陣 |
| `function` | 函數與圖形 | 對應關係、簡易表格與變化 | 座標平面、一次函數、二次函數、反比例 | 函數、合成函數、反函數、多項式函數、指數函數、對數函數 |
| `geometry` | 幾何與測量 | 平面圖形、周長、面積、體積、角度 | 三角形、四邊形、圓、全等、相似、幾何證明 | 平面向量、空間幾何、幾何證明、空間座標 |
| `trigonometry` | 三角函數 | 角度的直觀認識 | 銳角三角比、直角三角形邊角關係 | 三角函數、圖形、恆等式、和差角、倍角、正弦定理、餘弦定理 |
| `calculus` | 微積分 | 面積與變化的直觀經驗 | 可作變化率與面積的先備理解 | 極限、微分、導數、積分、面積、最佳化、運動問題 |
| `statistics` | 統計與資料分析 | 統計表、長條圖、平均數 | 平均數、中位數、眾數、盒狀圖、散布圖 | 統計量、相關、回歸、抽樣、資料分析 |
| `probability` | 機率與組合 | 簡單事件與可能性 | 樹狀圖、排列組合初步、古典機率 | 條件機率、排列組合、二項分布、期望值、機率分布 |
| `discrete_math` | 離散數學、數論與邏輯 | 規律、分類、簡單排列 | 數列、遞迴、整除、餘數、邏輯推理 | 命題邏輯、數論、圖論、遞迴、演算法、組合數學 |
| `linear_algebra` | 向量、矩陣與線性代數 | 不適用 | 平面向量初步，依課程規範調整 | 向量、矩陣、行列式、線性變換、線性方程組 |
| `analytic_geometry` | 解析幾何與圓錐曲線 | 座標定位 | 平面直角座標、直線方程式 | 直線、圓、拋物線、橢圓、雙曲線、軌跡問題 |
| `mathematical_modeling` | 數學建模與應用 | 生活情境、單位換算 | 速率、比例、成本、幾何應用 | 成長模型、最佳化、運動學、財務數學、資料模型 |
| `reasoning_proof` | 推理、論證與證明 | 找規律、說明理由 | 幾何證明、反例、條件推理 | 演繹證明、反證法、數學歸納法、充要條件 |
| `history_enrichment` | 資優、競賽與延伸數學 | 魔方陣、數獨、邏輯題 | 奧數數論、組合推理 | 競賽數學、數論、組合、圖論、進階證明 |

### 3.1 三角函數分類範例

若指定主題為三角函數，建議至少指定到子主題與能力層級，而不是只提供「三角函數」四字。

| 欄位 | 建議內容 |
|---|---|
| `curriculum_domain` | `trigonometry` |
| `topic` | 三角函數 |
| `subtopics` | 銳角三角比、特殊角、單位圓、圖形、和差角、倍角、半角、正弦定理、餘弦定理、解三角形、三角方程式 |
| `concepts` | sin、cos、tan 定義；弧度；週期性；奇偶性；象限符號；恆等式 |
| `skills` | 求值、化簡、證明、解方程式、圖形判讀、最大最小值、實際測量建模 |
| `strategies` | 畫單位圓、畫直角三角形、公式代換、代數化簡、輔助角法、圖形判讀、分類討論、反代驗算 |

## 4. 解題策略與題目形式架構

### 4.1 通用解題策略表

以下策略適用於不同年級與領域；它們應放在題目的 `strategies` 欄位，而不是取代課程主題。

| 策略類別 | 策略名稱 | 適用例子 |
|---|---|---|
| 視覺化與表徵 | 畫圖法、線段圖、座標圖、單位圓、樹狀圖、維恩圖、列表法 | 幾何、機率、集合、函數、三角函數 |
| 運算轉換 | 代入法、消去法、配方法、因式分解、通分、換元法、部分分式 | 代數、函數、微積分 |
| 結構辨識 | 規律觀察、分類討論、配對法、對稱性、週期性、不變量 | 數列、組合、三角函數、競賽數學 |
| 逆向思考 | 倒推法、反向運算、逆函數觀點、逆推條件 | 國小應用題、方程式、函數 |
| 建模策略 | 設未知數、列方程式、畫示意圖、單位分析、變數替換 | 應用問題、速率、成本、最佳化 |
| 論證策略 | 直接證明、反證法、數學歸納法、構造法、反例法 | 幾何、數論、集合、競賽題 |
| 檢核策略 | 反代驗算、估算、量綱檢查、圖形檢查、邊界值檢查 | 所有主題 |
| 數值與圖形分析 | 列表觀察、圖形判讀、單調性、極值、近似估計 | 函數、統計、微積分 |

### 4.2 原始試卷常用策略對照

| 策略 | 題目特徵 | 核心操作 | 常見錯誤 |
|---|---|---|---|
| 倒推法 | 已知最後結果，問原本數量 | 將運算反向且倒序處理 | 只反轉運算，卻沒有倒轉順序 |
| 假設法 | 兩種對象與總量、總腳數或盈虧關係 | 先全設為同一種，再補差 | 未理解替換一個對象造成的差量 |
| 和差法 | 已知兩量合計與相差量 | 小數量 =（和－差）÷ 2 | 只算出其中一量，未驗算兩條件 |
| 間隔法 | 植樹、鋸木頭、排隊、分段 | 區分物件數、段數、間隔數及端點 | 將段數直接當成次數或物件數 |
| 週期法 | 星期、珠子、圖形與輪流規律 | 找週期長度後以餘數判位 | 忽略餘數為 0 對應週期最後位置 |
| 重疊扣除法 | 兩類偏好、兩活動參與人數 | 合計後扣除重複計算者 | 直接相加而忽略重疊 |
| 配對法 | 連續整數加總、互補關係 | 首尾配對或配成固定和 | 配對數量錯誤或漏掉中間數 |

### 4.3 題目形式與認知層次

| `question_type` | 用途 | 適用情境 | 建議資料欄位 |
|---|---|---|---|
| `fill_in_and_reasoning` | 計算、推理填空 | 簡答、規律、化簡、求值 | 過程、答案、部分給分 |
| `multiple_choice` | 快速診斷概念或迷思 | 單一正解、辨識觀念 | 四個選項、迷思標籤、正確選項 |
| `short_answer` | 簡短計算或敘述 | 單步或少量步驟 | 解法、單位、驗算 |
| `application_reasoning` | 生活情境與建模 | 多步應用題 | 題意整理、策略、列式、驗算 |
| `proof` | 證明與論證 | 幾何、代數、數論 | 證明結構、關鍵論據、評分點 |
| `graph_interpretation` | 圖表與函數判讀 | 統計、函數、三角函數 | 圖形描述、判讀條件、答案 |
| `advanced_reasoning` | 資優或整合挑戰 | 多條件、策略整合、競賽型 | 子問題、完整推理、驗算 |
| `exploration_modeling` | 探究與建模 | 實作、資料、開放式情境 | 假設、模型、限制與評量規準 |

認知層次建議使用：`記憶`、`理解`、`應用`、`分析`、`評鑑`、`創造`。對一般試卷而言，以理解、應用與分析為主；資優、探究或證明題可提高至評鑑與創造。

## 6. 統整版建議 Prompt

以下 Prompt 是給 Perplexity 使用的完整版本。使用時只需替換 `{{...}}` 參數值；要求模型僅輸出合法 JSON，以利後續程式處理。

```text
你是一位台灣數學教育命題教師、跨學段課程設計者與題庫資料工程師。

請依照我提供的【年級】、【課程領域】、【主題】、【子主題】、【難度】、【題型與配分規劃】及【額外限制】，生成一份可由程式直接讀取的結構化數學試題資料。

你的工作不是製作 PDF、Word、試卷排版、頁首頁尾、姓名欄、作答欄或表格版面。你只能輸出：
1. 試題分類與課程標籤。
2. 每一題的題幹、選項、正確答案。
3. 可供詳解卷使用的完整逐步解題過程。
4. 驗算或合理性檢核。
5. 常見錯誤與迷思。
6. 每題的計分規劃與部分給分標準。

請使用繁體中文。題幹語言、數學符號、先備知識、計算複雜度、證明嚴謹度與情境設計，必須符合指定學段與課程主題。

# 年級適切性規則

1. 國小：
- 優先使用具體情境、圖像、表格與自然語言。
- 除非我明確指定，避免正式未知數方程式、複數、三角函數、微積分與超出學段的符號。
- 可使用倒推、列表、畫圖、假設、週期、間隔與和差等策略。

2. 國中：
- 可使用代數符號、方程式、不等式、座標幾何、函數、統計、機率與基本證明。
- 依指定單元使用根式、因式分解、相似形、圓與銳角三角比。
- 涉及三角相關內容時，區分「銳角三角比」與「高中三角函數」。

3. 高中：
- 可使用集合、函數、向量、矩陣、三角函數、極限、微積分、排列組合、條件機率與正式證明。
- 涉及三角函數時，必須明確標示角度使用「度」或「弧度」。
- 涉及微積分時，必須明確說明是否允許導數、定積分、換元積分或分部積分。
- 涉及證明時，依指定難度使用直接證明、反證法、數學歸納法、構造法或分類討論。

- S2：選擇題，5 題，每題 4 分，共 20 分。

# 命題規則

1. 每題必須有唯一且可驗證的答案；證明或開放題則須有明確評分規準。
2. 所有數字、單位、選項、日期、圖形條件、參數範圍、答案與詳解必須自行驗算。
3. 選擇題必須有且只有一個正確選項，錯誤選項必須對應合理的常見迷思。
4. 題目不可只替換範例中的人名、物品或數字；必須改變數學結構、條件關係、情境或所需策略。
5. 試卷難度須逐步提升，並避免多題重複考相同概念與相同解題結構。
6. 每題必須提供 solution_steps、verification、common_mistakes、scoring.rubric 與 teacher_tags。
7. 若題目允許多種解法，solution_steps 應提供一種主要且符合學段的解法；可在 alternative_methods 補充其他可接受方法。
8. 若題目涉及圖形，請以文字完整描述必要圖形條件；不要依賴未提供的圖片才能作答。
9. 若題目涉及三角函數，明確標示度數或弧度；若涉及三角函數圖形，明確定義函數式、區間、振幅、週期、相位或其他必要條件。
10. 若題目涉及微積分，明確定義函數的定義域、微分或積分範圍，以及是否要求精確值或近似值。

# 配分規則

1. 4 分填空、計算或簡答題：
- 1 至 2 分：核心觀念、公式、規律或策略正確。
- 1 至 2 分：計算、推理與最後答案正確。
- 若題目要求過程，只有答案但沒有過程時，最高不得超過 2 分。

2. 4 分選擇題：
- 選對 4 分；選錯 0 分。

3. 6 分應用推理題：
- 2 分：正確整理題意、圖形條件、已知與未知量，或選對策略。
- 2 分：列式、建模、推理或主要步驟正確。
- 1 分：計算或化簡正確。
- 1 分：完整答案、單位、範圍或驗算正確。

4. 10 分挑戰、證明或綜合題：
- 2 分：正確整理條件、定義與核心概念。
- 3 分：主要策略、關鍵定理、公式或論證方向正確。
- 3 分：後續多步推理、分類討論、計算或證明正確。
- 1 分：完整回答所有子問題。
- 1 分：驗算、合理性說明、反例檢查或條件檢核。

各題 rubric 分數加總必須等於 scoring.total；各題分數與各大題小計加總必須等於 total_score。

# 品質檢核

生成完成前，請在內部完成下列檢查，但不要輸出冗長檢核過程：

1. 每題答案是否唯一，或是否有明確且可執行的證明／開放題評分規準。
2. 所有計算、代數化簡、幾何條件、單位、參數範圍與答案是否一致。
3. 所有選擇題是否恰有一個正確選項。
4. 解題步驟、最終答案、驗算與配分規準是否相互一致。
5. 題數、各題分數、各大題小計與總分是否正確。
6. 題目是否符合年級、主題、難度與指定限制。
7. 是否避免重複的情境、數字結構、題型與策略。
8. 是否為每題建立可診斷的 common_mistakes 與 teacher_tags。
9. 涉及週期時，是否正確處理餘數，且餘數為 0 時是否對應週期最後位置。
10. 涉及間隔時，是否正確處理物件數、段數、間隔數與端點條件。
11. 涉及重疊時，是否正確扣除重複計算部分。
12. 涉及三角函數時，是否明確區分度數與弧度，並檢查象限、週期與定義域。
13. 涉及微積分時，是否檢查函數定義域、可微性、積分範圍與端點條件。
14. 涉及證明時，是否避免跳步，且每一個關鍵結論都有可接受的依據。
```
